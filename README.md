# A.R.T. — pitch board

A single pannable board: the paper dosing booklet rebuilt as practitioner,
family and owner software. Static — no build step, no dependencies.

Open `index.html`, or serve the folder:

    python3 -m http.server 8000

Drive it with the left sidebar (eight sections) or the two walkthroughs.
`1`–`8` jump to a section; drag to pan; ⌘-scroll to zoom.

Prototype with sample data. Not a live system.
